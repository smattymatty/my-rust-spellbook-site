# Research — designing the in-run spend layer (scorn)

Input for the scorn-economy `/grill-with-docs`. Synthesized from a web research
pass over incremental-game design writing and player sentiment, 2026-06-30.
Sources at the bottom. The headline: **a spend layer that is twelve flavors of
×2 is a spreadsheet, not a game** — the #1 thing that kills idle games.

## Categories of sink that create depth (mix 5–7, not just the first two)

- **A. Scalers (×prod / +flat / exponential)** — necessary connective tissue,
  insufficient alone. Scale prod ×~1.1, cost ×~1.15 so growth stays *noticeable*.
- **B. Mutually-exclusive choices** — the single biggest depth lever. Realm
  Grinder's one-faction-per-run rewrites the whole tree: "strategic choices,
  unlike standard upgrades which are simply collected." A purchase you can't take
  back turns number-go-up into "I made a build."
- **C. Synergy (A boosts B)** — Trimps: a cheap purchase becomes worth buying
  because of something *else* you own. Rewards system-knowledge.
- **D. Milestone / threshold unlocks (count-gated, not priced)** — goals that
  aren't "save up"; crossing one is a discrete dopamine event.
- **E. Automation as a tunable *system*, not a binary** — split into **unlock /
  interval / amount-or-threshold**. *This is the direct answer to "auto-push is
  boring": don't sell auto-push, sell the auto-push **control panel**.*
- **F. Softcaps + breakthrough upgrades** — builds the praised
  wall-then-breakthrough rhythm. The wall must read as a *puzzle with a known
  solution on the shopping list*, never as grind.
- **G. Spend-down / consumable tradeoffs** — a currency you *burn* for a one-shot
  boost; a finite re-allocatable pool is a decision engine (NGU).
- **H. Conversion / exchange** — turn X into Y, then upgrade the rate; changes the
  value of a resource you were ignoring.
- **I. Risk/reward gambles** — opt-in "push harder for a chance at double, or
  fumble" injects tension. Use sparingly.
- **J. Unlock-new-*mechanic* purchases** — strongest retention category. Payoff is
  a new *verb*, not a bigger number (Universal Paperclips' phase shifts).
- **K. Quality-of-life automation** — buy away tedium *after* the player has felt
  it. Pure goodwill.

## What players praise
Every reset unlocks a new system · the wall-then-breakthrough rhythm · build-
defining choices (Realm Grinder factions) · visible exponential payoff ·
automation that's *earned then tunable* · playstyle accommodation (short-clock vs
long-clock upgrades).

## What players criticize / quit over
"Just buy the same ×2 forever" · "no thinking, a Skinner box" · automation gated
too long (top early-quit cause) · walls that read as grind not puzzle · too idle /
no interaction · optimization that's all hidden math.

## Onboarding — your "5 pushes → free auto-push" plan is validated, with 2 refinements
Best practice: manual action first (feel the verb), then deliver first automation
*fast* (~10–15 min), free, as a *reward*. Refinements:
1. **Free unlock, paid tuning** — give auto-push away, then the next scorn goes to
   its interval/amount/threshold (category E). The gift opens a paid subsystem.
2. **Don't fully automate the interesting verb** — keep one active, rewarding verb
   the player *chooses* (a manual "Heave" stronger than auto), so the human stays
   the main character. Fits the project's philosophy exactly.
Sequence: manual push → first summit + roll-back → free auto-push (the
graduation) → **first real *choice* purchase within ~15 min** (front-load one
genuine decision; choices arriving too late is the #1 boredom-quit).

## Two-layer rhythm (keep scorn-resets-often from going stale)
- The **permanent** layer (defiance) should change the *starting conditions* of
  the frequent layer — run #50 starts where run #1 ended, not a replay.
- Keep the two currencies **categorically different**: scorn buys throughput +
  in-run build; **defiance buys *rules changes*** (new mechanics, higher caps,
  faster automation baselines, **new scorn-spend options**).
- Make the reset a **choice of *when*** (one more summit, or reset to compound?).

## Candidate scorn menu — 12 distinct flavors ([DECISION] vs [NGU])
1. Auto-pusher control panel: interval / strength / threshold (3 sinks) — [E] mostly NGU
2. **Heave** — active power-push, stronger than auto, on cooldown — [DECISION]
3. **Momentum streak** — stacking mult that decays if you stop — [DECISION]
4. **Stance fork (centerpiece)** — per-run pick ONE of Grind / Lurch / Patience; respec only on prestige — [DECISION]
5. Summit-scorn scaler — [NGU] honest workhorse
6. **Roll-back amplifier** — more scorn per roll-back but lose more height — [DECISION, spend-down]
7. **Slip gamble** — chance at double summit scorn, or slip back — [DECISION, opt-in]
8. **Second Wind (softcap-breaker)** — fatigue softcap near summit; a separate line dissolves it — [DECISION]
9. **Sisyphean Rhythm (synergy)** — auto-push level boosts Heave and vice-versa — [DECISION]
10. **Scorn → temporary defiance-preview buff** — burn scorn to taste a permanent effect — [DECISION]
11. Milestone unlocks (10/50/200 summits this run) — [NGU→DECISION]
12. QoL: auto-roll-back-at-threshold, bulk-buy, one-tap summit — [NGU]

**Assembly:** anchor on **#4 (Stance)** + **#8 (softcap-breaker)** for identity and
rhythm; use #2/#3/#6/#7/#10 for per-cycle decisions; let #1/#5/#11/#12 be
connective number-go-up for pacing. ~7 decision-bearing flavors vs 4–5 NGU —
clear of the "twelve ×2s" trap. **Reserve new-verb / new-mechanic unlocks for the
defiance tree**, so the permanent layer reshapes what scorn can even buy.
